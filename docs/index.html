Steelgum

A Rust framework for building and testing games with coding agents.

Run the prototype

Steelgum is in development. From the source checkout, run the playable prototype with Rust and Tcl/Tk (wish):

cargo run -p door-game -- --preview

Use the arrow keys or WASD to move, or press Space to watch the automated playthrough.

What it does

      
Steelgum keeps game rules, assets, and editable scenes in a normal source repository. People and coding agents can run the same simulation, inspect the results, and review changes before they land. Door Game is the first example.

      
    
        
  • Edit a room in JSON and review changes in Git.
    • 
        
  • Play the room yourself or replay the same game rules automatically.
    • 
        
  • Inspect the result from the Rust CLI or the graphical preview.
